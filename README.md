# Pão por Deus

Site institucional da Casa de Eventos Pão por Deus.

## Detalhes do projeto
- Site estático em HTML5 responsivo
- Hospedagem planejada no GitHub Pages
- Url de publicação esperada: https://eltonn.github.io/paopordeus/
- Link direto para WhatsApp e Instagram
- QR code integrado para divulgação offline

## Conteúdo
- `index.html`: página principal
- `styles.css`: estilos do site
- `plan_site.md`: plano de desenvolvimento do site
- `plan_mkt.md`: plano de marketing
- `plan_operacional.md`: plano operacional
- `plan_financeiro.md`: plano financeiro
- `plan_planilhas.md`: plano de planilhas e formulários
- `plan_planilhas_instrucoes.md`: instruções de criação das planilhas
- `plan_criterios_parceiros.md`: critérios de seleção de parceiros e fornecedores
- `plan_analise_negocio.md`: análise do negócio e ajustes
